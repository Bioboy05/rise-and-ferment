## Video Production Workflow

### Format A: Ken Burns + Voiceover
1. **Script** — Claude writes: hook, voiceover text, text overlay per frame, CTA
2. **Image** — Generate with Gemini Imagen 3 or reuse from Instagram
3. **Edit in CapCut** — Import image, apply:
   - Ken Burns effect (slow zoom/pan, 15-60s)
   - Text overlay (from script)
   - AI voiceover (Elena voice) or trending sound
   - Auto captions (CapCut built-in)
4. **Export** — 9:16 vertical, 1080x1920px
5. **Post** — Upload to TikTok at scheduled time
6. **Pinned comment** — Add RO translation + RO hashtags

### Format C: Slideshow Educativ
1. **Script** — Claude writes: hook, text per slide (5-7 frames), CTA
2. **Images** — Generate 5-7 images with Gemini or use text-on-background frames
3. **Edit in CapCut** — Import slides, apply:
   - Quick transitions (0.3-0.5s)
   - Text overlay per frame
   - Trending sound (no voiceover)
   - Auto captions if needed
4. **Export** — 9:16 vertical, 1080x1920px
5. **Post + Pinned comment** (same as above)

### What Claude delivers per video:
- Complete script (hook, text overlay per frame, voiceover text, CTA)
- Gemini image prompt or selected image
- Suggested trending sound category
- Pinned comment text (RO translation + hashtags)
- All saved to `content/tiktok/YYYY-MM-DD-<slug>/`

### File structure:
```
content/tiktok/
  2026-03-03-day3-smell/
    SCRIPT.md          # Full script with hook, overlays, voiceover
    PINNED-COMMENT.txt # Romanian translation + hashtags
    image-01.png       # Gemini generated image(s)
    PROMPT.txt         # Gemini prompt used
```

## TikTok vs Instagram: Key Differences

| **Frequency** | 4/week | 3/week |

| **Hashtags** | In caption + comment | In caption + pinned comment |
| **CTA** | "Link in bio" | "Follow for more" (growth phase) |
